# DAA To-Do List

A simple and user-friendly To-Do List application developed as a **Design and Analysis of Algorithms (DAA) project** using Python and Streamlit.

## 📌 Project Description

This application helps users organize and manage their daily tasks. Users can add tasks, mark tasks as completed, and manage tasks based on specific dates.

## ✨ Features

- ➕ Add new tasks
- 📅 Organize tasks by date
- ✅ Mark tasks as completed
- 🗑️ Manage tasks easily
- 📋 View tasks for a specific date
- 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

- **Python**
- **Streamlit**

## 🧠 DAA Concepts

The project demonstrates algorithmic thinking and efficient task management through:

- Searching tasks based on dates
- Updating task status
- Organizing and managing task data
- Use of data structures for storing tasks

## ▶️ How to Run

1. Install Python.
2. Install Streamlit.

    pip install streamlit

3. Run the application.

    streamlit run app_new.py

## 📂 Project Files

- `app_new.py` – Main Python source code
- `README.md` – Project documentation

## 🎯 Project Objective

The objective of this project is to develop a simple task management application while applying programming and algorithmic concepts learned in DAA.
